AMBILIGHT BRIDGE v5.6.2-C3-MOOD-ENGINE — feltölthető projekt
====================================================================

Ez az egyesített (MERGED) csomag. A "PROPOSED" javasolt csomag jó
firmware-javításait tartalmazza, DE a benne lévő végzetes UI-hiba
javítva: a duplikált escHtml eltávolítva, így a JavaScript ismét
hibátlanul lefut és a Control Center működik.

Miért kellett egyesíteni
-----------------------
- A PROPOSED csomag "kijavította" a nem létező P0-t (hiányzó escHtml)
  úgy, hogy hozzáadott egy function escHtml()-t — de az escHtml már
  létezett const formában. Két deklaráció ugyanabban a <script>-ben
  → SyntaxError: Identifier 'escHtml' has already been declared
  → az EGÉSZ UI script eldobva → halott oldal.
- Ebben a MERGED csomagban CSAK EGY escHtml van (const, 441. sor).

Belekerültek a PROPOSED jó firmware-javításai
---------------------------------------------
- Uptime: uptime_s (másodperc) + UI formatDurationSeconds() (s/min/h/d).
- Mood Dynamic Brightness VALÓBAN hat: effectiveMoodBrightness()
  (jelenet-luminancia + moodDynDepth).
- Diagnostics: /api/state küldi smart_seq, last_error mezőket.
- TV-status poll ROTÁLVA: 1 JointSPACE endpoint / ~1.25 s (nincs
  4-kéréses blokk a loopban).
- Ambilight polling: TV_FRAME_INTERVAL_MS 50 → 100 ms (a mért ~10–11 Hz
  TV-frissítéshez igazodva).
- 3-állapotú TV power modell: tv_power="unknown" + tv_signal +
  tv_power_reason + tv_output_off (nincs kitalált POWER állapot).
- Read API auth: /api/state, /realtime, /capabilities, /topology
  webAuthCheck mögött; /api/scan provisioning miatt nyitva. A UI 401-re
  bekéri a jelszót és Basic auth-tal újrapróbál (apiH/api()).
- SI / human-readable UI-egységek (%, °, Hz, idő), a firmware belső
  0–255 reprezentációt kap vissza.
- "TV fényerő követése" letiltva/dokumentálva (v1 API-n nem támogatott).

Szándékosan NEM beépített (változatlan)
---------------------------------------
- Valódi JointSPACE persistent/stream (a TV keep-alive nem stabil).
- Valódi TV POWER detektálás (/1/system/power = 404 ezen a TV-n).
- Kelvin színhőmérséklet (nincs API-paraméter).
- WebSocket Basic Auth (külön integrációs feladat).
