# Ambilight Bridge v5.6.1-C3-HARDENED-MERGED

This release is the canonical program for the current Ambilight Bridge ESP32-C3 project.

Core changes: authenticated read APIs, rotating Philips JointSPACE TV status polling, TV power state reported as unknown where unsupported, Mood dynamic brightness application, and human-facing UI units with raw API compatibility.

Static source validation was performed. Actual ESP32-C3 compilation and hardware regression must still be run with the target board and toolchain.
