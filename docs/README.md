# Documentation

The `docs/` directory is also the intended GitHub Pages source directory.

## Published browser UI

`docs/index.html` contains the current complete Ambilight Bridge V5 browser control center.

If GitHub Pages is enabled for this repository, the site can be published from:

```text
main branch
/docs
```

Expected Pages URL:

`https://ispazoli.github.io/Ambilight_ESP/`

The exact availability depends on the repository Pages configuration.

## Documentation policy

Documentation must describe verified behavior. Do not mark features as working until the corresponding firmware/browser test has actually been performed.
